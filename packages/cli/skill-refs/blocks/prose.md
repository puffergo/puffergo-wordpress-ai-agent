# 正文：Markdown 写法

文章、案例的正文，还有产品详情里的大段文字，都写成 Markdown，存成 `.md` 文件。它到网站上是 WordPress 原生区块（段落、标题、列表…），客户在编辑器里就能像平常一样改字、回车分段、加粗、换图片，不用找你。

**页面（`layout` 是 `fullWidth`）不这样写**，它整页都是版式，用静态区块（`static.md`）。

## 能写什么

只有下面这些，别的都会被网站拒绝（报 `prose_unsupported`，带行号）：

| 写法 | 变成 |
|---|---|
| `## 标题`、`### 标题`、`#### 标题` | 二、三、四级标题 |
| 一段话（中间换行不分段，空一行才分段） | 段落 |
| `- 项目` 或 `1. 项目` | 列表，只能一层 |
| `> 引用的话` | 引用块（空的 `>` 一行分段） |
| 表格：表头行、`---` 分隔行、数据行，每行都用竖线隔开单元格 | 表格 |
| `![图片说明](images/xxx.jpg)` 单独占一行 | 图片，居中 |
| 视频链接单独占一行（YouTube、Vimeo…） | 段落，前台自动变成播放器 |
| `---` 单独占一行 | 分隔线 |
| `**粗体**`、`*斜体*`、`` `代码` ``、`[文字](网址)` | 行内格式 |

## 不能写什么

- **`#` 一级标题**：文章的大标题网站模板已经出了，正文从 `##` 开始。`#####` 以下也没有。
- **任何 HTML**：`<div>`、`<span>`、`<br>`、`class="…"`、内联样式，一个都不行。要多列排版、卡片、带背景色的区段，那一段改用静态区块（`.html`）。
- **嵌套列表**（列表项里再缩进一层）。
- **轮播、表单、弹窗**：正文做不了，告诉客户可以在 WordPress 编辑器里加现成的组件。

正文里要写数学式或代码里的 `<`、`&`，照常写，网站会当文字处理；只有像标签的写法（`<span>`）才会被拒。

表格长这样（第二行的 `---` 不能少）：

```markdown
| Rating | Dust | Water |
| --- | --- | --- |
| IP65 | Tight | Jets |
| IP66 | Tight | Waves |
```

## 几件容易踩的事

- **图片**写相对路径（相对这个 `.md` 文件），如 `![Gear motor housing](images/gear.jpg)`，脚本会自动上传。每张图都要写图片说明（alt），写清图里是什么。网上的图用完整 `https://` 链接。图片一律居中——Markdown 没法写对齐，所以客户在编辑器里改了对齐，你下次推正文会把它改回居中，要别的对齐请他推完再改。
- **想让 `*` `_` `#` `|` 这些符号当普通字符**，前面加反斜杠：`5\*8`、`\# 1 供应商`。读回来的正文里如果看到反斜杠，那就是客户原文里的符号，别删。
- **一个 `.md` 文件就是一段正文**，里面可以有很多段落和标题，不用一段一个文件。要在正文中间插一个 PufferGo 区段，就把正文拆成两个 `.md` 文件，中间放那个 `.html` 或 `.json`。
- **视频**：把链接单独放一行（前后各空一行），如 `https://www.youtube.com/watch?v=…`，WordPress 前台会自动变成播放器。**不要**写 `<iframe>`（会被拒），也不要写 `{"type": "video"}`（那是产品详情的形状，见 `blocks.md`）。这一行在编辑器里是一个带链接的段落、不是视频区块，客户看到的是链接而不是播放框，这是正常的——好处是它还算正文，客户能直接编辑、你也能原样读回来。
- **改正文之前先 `pages get`**：客户可能已经在编辑器里改过，拿最新的改，不要用旧文件。
